# Roadmap

The milestones: goals made of specs, in order of priority within each status. Each milestone's page has its goal,
scope and results, and the website shows the same at [/roadmap](https://timelake.dev/roadmap). A milestone is a file
here with front matter (`number`, `title`, `status`: `done`, `in-progress`, `planned` or `exploring`, `versions`,
`updated`, a one-line `description` for the roadmap, `specs`, and optionally `issues`); the list below and each file's
header and spec table are generated by `uv run python scripts/spec_index.py`.

## Exploring

**Exploring**. AI agents query your data within the permissions you set, and a benchmark of whether they answer better, and for less, when it's in Timelake.

Specs: [Agent access with permission sets](../0040-agent-access.md) (planned), [Agent benchmark](../0046-agent-benchmark.md) (planned).

### [Apps and dashboards](apps.md)

**Exploring**. Small ready-made files for frontends, refreshed on every write, and your Python functions applied automatically like rollups.

Specs: [Static read models](../0038-read-models.md) (planned), [Computed metrics](../0039-computed-metrics.md) (planned).

### [Edge and devices](edge.md)

**Exploring**. Write on devices and gateways; Timelake moves the data to the lake and serves recent data when the uplink is down.

Specs: [Device sync](../0041-device-sync.md) (planned), [Edge gateway](../0042-edge-gateway.md) (planned).

### [Server mode](server-mode.md)

**Exploring**. Timelake as a database on one machine, with the bucket as the copy. Then TSBS run with its own tools, next to published results.

Specs: [Server mode](../0043-server-mode.md) (planned).

## Done

### [v0: a maintenance-free time-series table on S3](v0.md)

**Done** · versions 0.1.0. Open Iceberg tables on any object store with compaction, dedup, retention and a last-value index built in, read faster than naive S3 Tables or Lance.

Specs: [Iceberg tables](../0001-iceberg-tables.md) (done), [Commits](../0002-commits.md) (done), [Object-store catalog](../0003-object-store-catalog.md) (done), [Time-series table contract](../0004-table-contract.md) (in progress), [File layout and encodings](../0005-file-layout.md) (in progress), [Last-value index](../0006-last-value-index.md) (in progress), [Appends](../0011-appends.md) (done), [Import and migration](../0016-import.md) (in progress), [Compaction](../0019-compaction.md) (done), [Maintenance runs, retention and expiry](../0020-maintenance.md) (in progress), [Timelake reader](../0021-reader.md) (in progress), [Time buckets and gap filling](../0029-gap-filling.md) (done), [Benchmark harness: timebench](../0044-timebench.md) (in progress).

### [Fast first queries on object storage](fast-first-queries.md)

**Done** · versions 0.2.0–0.7.0. First queries on S3 in one or two round trips instead of six or seven, repeat queries from a local cache, and scans that read and decode less.

Specs: [Commits](../0002-commits.md) (done), [One-request table state and version checks](../0007-table-head.md) (done), [Block cache](../0022-block-cache.md) (done), [Filter pushdown](../0023-filter-pushdown.md) (done), [Pruning with long IN lists](../0024-in-list-pruning.md) (done), [Newest-first scans](../0025-newest-first.md) (done), [File layout and encodings](../0005-file-layout.md) (in progress).

### [Installable, upgradable, switchable](upgrades-and-settings.md)

**Done** · versions 0.3.0–0.5.0. Install from crates.io, PyPI and npm, upgrade tables without data loss, and turn every feature on or off with a setting.

Specs: [Table format versions and upgrades](../0008-format-versions.md) (done), [Settings](../0009-settings.md) (done).

### [Exact answers before compaction](exact-before-compaction.md)

**Done** · versions 0.5.0. Rows sent twice count once, from the moment they land: dedup on read, an insertion time per row, and cold partitions compacted sooner.

Specs: [Late data and dedup on read](../0012-late-data-and-dedup.md) (done), [Compaction](../0019-compaction.md) (done).

### [Writes from JavaScript](javascript-writes.md)

**Done** · versions 0.6.0. Append to tables and keep them compacted from Cloudflare Workers and other JavaScript runtimes, in fixed memory.

Specs: [Writes from WebAssembly](../0013-wasm-writes.md) (done), [Compaction](../0019-compaction.md) (done), [Appends](../0011-appends.md) (done).
