# Credits

Timelake is built on other open-source projects and borrows ideas from many more. We take ideas, never code. Thank you to everyone behind them.

## Built on

| Project | What it does in Timelake |
| --- | --- |
| [Apache Iceberg](https://iceberg.apache.org) | The table format |
| [Apache Parquet](https://parquet.apache.org) | The data files |
| [Apache Arrow](https://arrow.apache.org) | Data in memory |
| [Apache DataFusion](https://datafusion.apache.org) | The query engine |
| [iceberg-rust](https://github.com/apache/iceberg-rust), [object_store](https://github.com/apache/arrow-rs-object-store) | Iceberg types, and every read and write to storage |
| [DuckDB](https://duckdb.org) | Reading tables with plain SQL |

## Ideas we borrowed

| Idea | From |
| --- | --- |
| Size-tiered compaction | [Apache Cassandra](https://cassandra.apache.org) |
| Tables readable with no catalog service | Iceberg's Hadoop catalog |
| Staging a backfill on a branch, then publishing it | Iceberg branches |
| Rollup tables of per-bucket aggregates | [Apache Druid](https://druid.apache.org) |
| Answering a query from a matching rollup | [Apache Calcite](https://calcite.apache.org) |
| A time window's first, smallest, largest and last points (`m4`) | [Apache IoTDB](https://iotdb.apache.org) |
| Object-store reads split into parallel requests of a few MiB | Durner, Leis, and Neumann, [VLDB 2023](https://www.vldb.org/pvldb/vol16/p2769-durner.pdf) |
